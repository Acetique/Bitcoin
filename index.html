Le verdict utilise le MVRV Ratio et le Z-Score d’Explore21.

Repères indicatifs : MVRV < 1 = BTC sous son prix réalisé (zone de capitulation possible) ; retour au-dessus de 1 = reprise potentielle. Z-Score < 0 = sous-évaluation historique ; retour au-dessus de 0 = amélioration. Ces deux indicateurs sont liés et ne constituent pas des confirmations indépendantes. Une fin de bear market exige aussi une confirmation de tendance hebdomadaire, non évaluée ici.
